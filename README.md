# ボンバークマン（BOMBA-KUMAN）

Node.js 18以上、追加パッケージ不要のブラウザ用チーム対戦ゲーム。

## 起動

WindowsはZIPを展開して `START-WINDOWS.bat` をダブルクリック。
ターミナルの場合はTEST2フォルダーで `npm start`。
ブラウザで http://localhost:3000 を開き、起動ウィンドウは開いたままにしてください。
`PORT` でポート変更可。

## 対戦と操作

- 16×16マス、1VS1〜4VS4。人間1名、残りはCPU（オンライン対戦なし）。
- WASD／矢印：移動。0（テンキー0も可）またはスペース：攻撃。P：一時停止。Enter：必殺技。
- スマホ：画面左下の◎1個の移動パッド（上下左右を押す・なぞる）、右下の攻撃ボタン、その右に必殺技ボタン。画面下に固定表示。
- Enterは開始前にはバトル開始、対戦中には必殺技として機能。
- 相手全員を退場させるか、60秒経過時はボム側の逃亡成功で勝利。3ラウンド先取。
- 撃破されたキャラは翼と輪を付けて天使になり、約2秒かけて舞い上がります。
- 最後の撃破後は対戦を止め、2秒の昇天演出後に結果画面を表示。時間切れ時は生存するボム側キャラが枠外へ走り去る約2秒の演出を表示します。

## 3種類のアイテム

両チーム共通。各能力は独立して初期レベル1、取得ごとに1段階上がり、レベル3で上限。
フィールドには色付きのSP／AT／RGとUPを表示。右のパネルはアイコンと3つの塗り分けゲージで段階を表示。

| アイテム | 爆弾ガール | パック側 |
| --- | --- | --- |
| 青SP：速度 | 1→1.2→1.4倍 | 1→1.2→1.4倍 |
| 橙AT：攻撃 | 同時設置1→2→3個 | 手動攻撃の再攻撃待ち2秒→1秒→なし |
| 紫RG：範囲 | 爆風の各方向の射程2→5→画面端まで（MAX） | 自分マスのみ→正面1マス追加→正面2マス追加 |

SPは移動とCPUの退避予測に同じ倍率を適用。初期速度は1マス約0.267秒。
爆風は全段階で壁・ブロックに遮られ、面全体を埋める攻撃ではありません。

## 攻撃

- 爆弾ガール：設置から1.8秒後に十字爆発。初期から爆弾キックが可能。誘爆あり。自分・味方にも命中。
- パック側：接触すると待ち時間中でも即捕食。敵のみが対象。
- 手動捕食の予備動作後の命中時間は0.12秒、演出は0.5秒。命中後の追加判定なし。
- ATレベル1・2は押した瞬間に1回。AT最大では長押し連射が可能です。
- AT最大は追加の再攻撃待ちなし。現在の一振りの命中時間が終わると次の攻撃を開始し、重複した無制限の攻撃生成を防ぎます。
- パック側は爆弾を通過・捕食できず、壁や爆弾の向こうへも捕食できません。ボム側は爆弾のマスへ進むと蹴って転がせます。
- 初期RGでも隣接ブロックを2回かじって破壊可能。敵への攻撃範囲とは別です。

## キャラクター

- 選択カード名：灼熱の爆弾ガール／冷徹の捕獲マスター。
- ボム側：レゼベース。暗紫の髪・緑の瞳。赤／青／黒／白は衣装に使用。
- パック側：マキマベース。赤茶の三つ編み・金色の輪のある瞳・パックマン風リボン。黄／オレンジ／桃／緑で識別。
- 選択イラストは顔アップ。ボム側はチョーカーと爆弾チャーム付き。
- ゲーム内キャラの絵と、選択用のイラストは個別の素材です。

## 確認

`npm test` で移動、攻撃、接触捕食、SP／AT／RG、CPU回避、結果の2秒待ちを検証。
調整値と戦闘ルールは `battle.js`、描画と操作は `game.js`。

## 必殺技（各キャラ1ラウンド3回）

各キャラは1ラウンドに3回使用可能。次のラウンド開始時に、人間・CPUとも残り回数が3回へ復活します。PCの右パネルとスマホの攻撃ボタン右側に、技名×残数を表示。PCはEnterキー／テンキーEnter、ボタンのクリックでも発動できます。長押しでは連続消費しません。

- レゼ側「瞬速」：進行方向に最大2マス瞬間移動。通過する破壊可能ブロックを壊し、移動前・途中に0.3秒の残像。破壊不能壁の手前で止まり（瞬速時のみ爆弾を通過可）、、1マスも進めない場合は消費しません。発光は無敵ではないので、パック側への接触や移動先の爆風は有効です。
- マキマ側「不死」：1.5秒間その場に止まって無敵。移動・通常攻撃・再度の不死使用を停止し、発動前の未完了の手動攻撃も終了します。接触での即捕食は従来どおり。
- 瞬速は使用後0.3秒間、不死は1.5秒間、キャラが光りながら点滅します。停止・結果演出中は新規使用できません。
- CPUも各3回の制限で、退避や危険時の防御に使用します。

移動パッドは1個の◎を中心から上下左右へ押して操作。中央は停止、指を離すと停止。PC移動は矢印キー（WASDも可）。右上のカード説明は「爆撃×瞬速」「捕食×不死」、名前は1行表示。

## 初期からの爆弾キック

ボム側は爆弾へ向かって移動すると、その方向へ爆弾を転がします。追加ボタンやアイテムは不要。壁・ブロック・他の爆弾・生存キャラの手前で止まります。行き先がふさがっていれば蹴れません。蹴っても爆発までの残り時間は延長されず、設置から1.8秒で爆発します。誘爆も有効。CPUは転がる経路上の爆風も危険として判断します。

ボム側CPUは蹴った先の爆風が敵に届くかを予測し、安全に退避できるキック攻撃を優先します。隣接爆弾だけでなく、自分で設置→1マス下がる→敵へ蹴り出す動作も選択。味方の退避経路と残り導火線時間を確認します。

英語ロゴはBOMB＋大きなA＋KUMA＋N。AとKUMAを赤く表示し、横棒は延長しません。

上部HUDは生存人数とラウンド勝利数を分け、勝利数を「●〇〇」の3つの丸で表示。中央はラウンド数と残り時間です。

スマホの移動パッドは、指が最も寄っている上下左右の1方向だけを入力。斜めの同時入力や、壁で他方向に切り替わる動作はありません。PCの上部HUDは大きなチーム名・人数バッジ・勝利ゲージへ変更し、説明文の最小サイズは14px。英語ロゴのAは横棒を伸ばさず、大きく表示しています。

移動パッドは中心から直径の20%分より深く動かすと入力（従来10%）。中央付近の小さな指の動きでは移動せず、中心から離れた先では最も寄っている1方向へ動き、離すと停止。

移動パッドで押し始めた指は、円の外へ動かしても追跡を維持。指を離す／操作がキャンセルされるまで入力し、画面外へフォーカスが移る場合は停止します。PCではキャッチコピーとタイトルの2行とし、対戦名をタイトル右へ18pxの下揃えで表示します。

スマホは左の移動操作エリアを広げ、触れた位置を基準にドラッグして操作。押しただけでは動かず、一定距離まで倒すと最も寄った1方向へ入力します。円の外でも追跡し、離すと停止。勝利マークはPC・スマホとも文字ではなく均一な円で表示。タイトル横は「～爆弾ガール VS 捕獲マスター～」です。
