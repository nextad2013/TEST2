# NEON DUEL

日本語の2D対CPU格闘ゲーム。Node.js 18以上で `npm start`。ポート3000で起動します（`PORT` で変更可能）。外部パッケージのインストールは不要です。

- Enter: 開始・再戦、← → / A D: 移動
- J: パンチ、K: キック、L長押し: 防御
- ↑ / W: ジャンプ、↓ / S: しゃがみ
- タッチ操作: 画面下の各ボタン

体力20、頭への命中2、その他1。防御でダメージ0。射程内のパンチをしゃがみ、キックをジャンプで回避すると、1.2秒間、次の命中のダメージが2倍。60秒経過で残り体力を比較。同体力は引き分け。

`npm test` でダメージ・回避・防御・カウンター期限・射程・KOを検証します。
