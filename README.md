# ボンバックマン～爆弾娘VSパックガール

TEST2用ブラウザ試作品。Node.js 18以上、追加パッケージ不要。

## 起動

```sh
cd /workspace/TEST2
npm start
```

ブラウザで http://localhost:3000 を開く。`PORT` でポート変更可。

## 操作

- WASD / 矢印：移動、スペース：攻撃、P：一時停止
- スマートフォン：画面下の方向ボタンと攻撃ボタン
- チームと1VS1〜4VS4を選択。人間1名、他はCPU（オンライン対戦未実装）。
- 120秒、敵全滅または生存人数で判定。3ラウンド先取。
- 爆風は自分・味方にも命中。捕食は敵のみ。退場後はCPU戦を観戦。
- 爆弾：2秒後に十字爆発、壁で遮断、誘爆あり。
- 爆風：全長1/3→2/3→MAX。設置数：1→2→3。
- 捕食：自分のマスのみ→正面1→正面2マス（常に自分のマスを含む）。速度：1→1.5→2倍。
- パックガールはブロックを2回かじって破壊。爆弾は食べられず、通過もできない。捕食も爆弾で遮られる。
- ブロックから出る「UP」で強化。どちらのチームも取得可能。
- 紫UP（Ⅰ）：爆弾娘の爆風／パックガールの捕食。茶UP（Ⅱ）：設置数／移動速度。
- キャラクターはコードで描画したオリジナルのデフォルメ顔アイコン。

`npm test` で戦闘ルールと全人数のCPU戦を検証。
調整値は `battle.js` の `CONFIG`、ゲームルールも同ファイル。
昨日のゲームは `/workspace/work/neon-duel-backup/` にバックアップ。

## フィールドと見分け方

- 全人数で16×16マス固定（外周の壁を含む）。
- 爆弾娘：レゼの人間姿を参考に、暗紫の髪・流した前髪・緑の瞳・白いノースリーブ襟・黒いチョーカーに統一。帽子・導火線・おさげはなし。1〜4番は赤・青・黒・白。
- パックガール：丸く口を開けたクチバシ風リボン1つで統一。1〜4番は黄・オレンジ・桃・緑。
- YOUマーカーは操作キャラ。識別用の色は爆弾娘では腰と腕の衣装、パックガールでは衣装と被り物に使用。髪はパックガールが赤茶、爆弾娘が暗紫。
- アイテムは共通の紫と茶の「UP」。チーム選択欄に効果の凡例を表示。

CPUは誘爆の前倒しを含む爆発時刻と退避ルートを計算。逃げ道のない爆弾設置を避け、味方の退避も確認します。捕食は攻撃中の現在位置と正面に当たり、同じマスで重なった敵も対象です。

初期移動は初代風のテンポを目安に1マス約0.267秒（約3.75マス/秒）へ調整。原作の完全な実測再現ではありません。パックガールの速度倍率（1／1.5／2倍）とCPUの判断ロジックは維持。被り物は髪の輪郭に重ねて装着し、導火線1本／クチバシ飾り1つを小さくまとめています。

捕食中は攻撃範囲のマスに、攻撃方向へ口を開けるクチバシアイコンを表示。発動中は口が閉じるアニメーションと先端の光で攻撃を示します。パックガールは茶髪のはっきりした前髪、爆弾娘は暗紫のボブとチョーカーに調整。CPU・攻撃判定は変更していません。

爆弾娘の描画を専用化。低い位置でまとめた暗紫の髪、片側へ長く流す前髪、緑の瞳、白い襟と黒いチョーカーを強調。パックガールの描画・ゲームルール・CPUは維持しています。

移動は従来の速度・マス判定を維持し、移動タイマーに合わせて描画座標を線形補間。CPUを含む全キャラがマス間を滑らかに移動します。爆弾娘のチョーカーはあごより下の露出した首元に移し、口と分離しています。

## 捕食の制限

- 捕食はスペース／攻撃ボタンを押した瞬間に1回だけ発動。長押しでは再発動せず、離してから押し直す必要があります。待ち時間中に押した入力の予約はありません。
- 攻撃アイコンは発動から0.5秒で消えます。予備動作後の有効な命中時間を0.24秒から0.12秒に短縮。命中したらその攻撃の判定は終了し、残りは薄い表示になります。
- CPUにも0.5秒表示／0.12秒の命中時間と従来の再攻撃待ち時間を適用。爆弾娘の操作・速度は維持。

## パックガールのゲーム内キャラクター

候補②のマキマベースへ変更。赤茶の髪・まっすぐな前髪・横の三つ編み・金色の輪のある瞳・白シャツと黒ネクタイ・パックマン風リボン1つを、マス内のデフォルメキャラとして描画。黄／オレンジ／桃／緑はリボン・袖・腰に使用。チーム選択アイコンにも同じキャラを反映。歩行中は手足と三つ編みが小さく動きます。爆弾娘の描画、攻撃判定、CPU、移動速度は変更なし。

マキマ側（パックガール）の輪郭を丸顔から小さなV字の顎へ調整。あご下の肌と開いた白襟を見せ、黒ネクタイは縦長の結び目と剣先に分けて描画。首輪は使用せず、レゼ側の描画は変更していません。

## 捕食範囲と選択イラスト

- 初期は自分と重なった敵のみ。紫UPを1回で正面1マス、2回で正面2マスまで拡大（最大）。
- 壁・爆弾で攻撃を遮るルールは維持。初期でも進行不能にならないよう、隣接ブロックをかじる操作は可能（敵への射程とは別）。
- 右上の選択カードはマキマ候補②の顔アップ／レゼ候補④の顔アップ（チョーカー付き）へ変更。ゲーム内キャラの描画はそのまま。

爆弾娘は茶UPに連動して移動速度も強化：初期1倍→UP1は1.3倍→UP2は1.6倍（初期速度への加算、最大60%増）。同時設置数1→2→3個も維持。CPUの退避時間予測と移動描画にも同じ速度倍率を使用。パックガールの速度倍率は従来どおり。レゼの選択イラストは約5%引き、顎の位置をマキマと近づけています。

## 接触による自動捕食

パックガールと爆弾娘が同じマスに触れると、スペースを押さなくても即座に捕食します。移動した側や手動攻撃の待ち時間にかかわらず発動。0.5秒のクチバシ演出と捕食音を再生し、接触演出から遠距離の追加判定は出しません。正面への手動攻撃は従来どおり。レゼの選択絵は引く前の大きめに戻し、マキマの絵も少し拡大して左右の髪を枠内に収めています。
