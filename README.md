# ボンバックマン～ボムガールVSパックレディ

Node.js 18以上、追加パッケージ不要のブラウザ用チーム対戦ゲーム。

## 起動

WindowsはZIPを展開して `START-WINDOWS.bat` をダブルクリック。
ターミナルの場合はTEST2フォルダーで `npm start`。
ブラウザで http://localhost:3000 を開き、起動ウィンドウは開いたままにしてください。
`PORT` でポート変更可。

## 対戦と操作

- 16×16マス、1VS1〜4VS4。人間1名、残りはCPU（オンライン対戦なし）。
- WASD／矢印：移動。Enterまたはスペース：攻撃。P：一時停止。0（テンキー0も可）：必殺技。
- スマホ：画面左下の◎方向ボタン、右下の攻撃ボタン、その右に必殺技ボタン。画面下に固定表示。
- Enterは開始前にはバトル開始、対戦中には攻撃として機能。
- 相手全員を退場させるか、120秒経過時の生存人数で勝敗判定。3ラウンド先取。
- 撃破されたキャラは翼と輪を付けて天使になり、約2秒かけて舞い上がります。
- 最後の撃破後は対戦を止め、2秒の昇天演出後に結果画面を表示。時間切れ時も2秒待ちます。

## 3種類のアイテム

両チーム共通。各能力は独立して初期レベル1、取得ごとに1段階上がり、レベル3で上限。
フィールドには色付きのSP／AT／RGとUPを表示。右のパネルはアイコンと3つの塗り分けゲージで段階を表示。

| アイテム | ボムガール | パック側 |
| --- | --- | --- |
| 青SP：速度 | 1→1.2→1.4倍 | 1→1.2→1.4倍 |
| 橙AT：攻撃 | 同時設置1→2→3個 | 手動攻撃の再攻撃待ち2秒→1秒→なし |
| 紫RG：範囲 | 爆風の各方向の射程3→6→画面端まで | 自分マスのみ→正面1マス追加→正面2マス追加 |

SPは移動とCPUの退避予測に同じ倍率を適用。初期速度は1マス約0.267秒。
爆風は全段階で壁・ブロックに遮られ、面全体を埋める攻撃ではありません。

## 攻撃

- ボムガール：設置から2秒後に十字爆発。誘爆あり。自分・味方にも命中。
- パック側：接触すると待ち時間中でも即捕食。敵のみが対象。
- 手動捕食の予備動作後の命中時間は0.12秒、演出は0.5秒。命中後の追加判定なし。
- ATレベル1・2は押した瞬間に1回。AT最大では長押し連射が可能です。
- AT最大は追加の再攻撃待ちなし。現在の一振りの命中時間が終わると次の攻撃を開始し、重複した無制限の攻撃生成を防ぎます。
- 爆弾は通過・捕食できず、壁や爆弾の向こうへも捕食できません。
- 初期RGでも隣接ブロックを2回かじって破壊可能。敵への攻撃範囲とは別です。

## キャラクター

- 選択カード名：灼熱のボムガール／冷徹のパックマスター。
- ボム側：レゼベース。暗紫の髪・緑の瞳。赤／青／黒／白は衣装に使用。
- パック側：マキマベース。赤茶の三つ編み・金色の輪のある瞳・パックマン風リボン。黄／オレンジ／桃／緑で識別。
- 選択イラストは顔アップ。ボム側はチョーカーと爆弾チャーム付き。
- ゲーム内キャラの絵と、選択用のイラストは個別の素材です。

## 確認

`npm test` で移動、攻撃、接触捕食、SP／AT／RG、CPU回避、結果の2秒待ちを検証。
調整値と戦闘ルールは `battle.js`、描画と操作は `game.js`。

## 必殺技（各キャラ1試合3回）

3ラウンド先取の1試合を通して各キャラ3回。次のラウンドでも残数を引き継ぎ、新しい試合・設定リセットで3回に戻ります。PCの右パネルとスマホの攻撃ボタン右側に、技名×残数を表示。PCは0キー／テンキー0、ボタンのクリックでも発動できます。長押しでは連続消費しません。

- レゼ側「瞬速」：進行方向に最大2マス瞬間移動。通過する破壊可能ブロックを壊し、移動前・途中に0.2秒の残像。破壊不能壁と爆弾の手前で止まり、1マスも進めない場合は消費しません。発光は無敵ではないので、パック側への接触や移動先の爆風は有効です。
- マキマ側「防壁」：2秒間その場に止まって無敵。移動・通常攻撃・再度の防壁使用を停止し、発動前の未完了の手動攻撃も終了します。接触での即捕食は従来どおり。
- 瞬速は使用後0.5秒間、防壁は2秒間、キャラが光りながら点滅します。停止・結果演出中は新規使用できません。
- CPUも各3回の制限で、退避や危険時の防御に使用します。
